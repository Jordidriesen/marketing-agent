# KI-Schreibmuster: Deutsch

This file extends the universal patterns in SKILL.md with German-specific AI tells.
Load this file when the input text is in German.

---

## Tier 1 — Harte Streichungen (deutsche Entsprechungen)

| Muster | Beispiele | Korrektur |
|---|---|---|
| Chatbot-Artefakte | "Großartige Frage!", "Ich hoffe, das hilft!", "Zögern Sie nicht, mich zu kontaktieren...", "Natürlich!", "Selbstverständlich!" | Vollständig löschen |
| Kopula-Vermeidung | dient als, fungiert als, gilt als, stellt ... dar, repräsentiert | Ersetzen durch ist/sind/hat |
| Kollaboratives Gerüst | "Hier ist eine Übersicht...", "Möchten Sie, dass ich...", "Lassen Sie mich das näher erläutern..." | Vollständig löschen |
| Wissensabschneidungs-Disclaimer | "nach meinem letzten Kenntnisstand", "obwohl spezifische Details begrenzt sind" | Löschen oder durch echte Quellenangabe ersetzen |

## Tier 2 — KI-Vokabular (Deutsch)

**Verben:** nutzen/nutzen (overused), optimieren, ermöglichen (overused), fördern,
stärken, unterstreichen, enthüllen, navigieren (figurativ), rationalisieren, verbessern,
kultivieren, beleuchten, hervorheben (als Verb), erzielen, bewerkstelligen, verdeutlichen,
aufzeigen (overused), voranbringen

**Adjektive:** robust, umfassend (overused), entscheidend/maßgeblich (overused), vital,
transformativ, bahnbrechend, innovativ, nahtlos, vielschichtig, holistisch, tiefgreifend,
wegweisend, zukunftsorientiert, nachhaltig (als Füllwort), strategisch (als Füllwort),
resilient

**Substantive/Ausdrücke:** Landschaft (abstrakt), Ökosystem (abstrakt), Synergie, Paradigma,
Myriade von, Fülle von, Zusammenspiel, Komplexität (overused), Dynamiken, Herausforderungen
(als Boilerplate), Potenziale, Mehrwert (overused)

**Akademische/bürokratische Varianten:** im Hinblick auf, im Rahmen von, mit Blick auf,
hinsichtlich, diesbezüglich, es sei darauf hingewiesen dass, es gilt zu beachten,
im Zuge von, vor dem Hintergrund von, in Bezug auf, seitens (overused)

## Tier 3 — Strukturelle Verräter (Deutsch)

| Muster | Beschreibung |
|---|---|
| Nominalisierungs-Stacking | **Das ist das stärkste deutsche KI-Signal.** Häufung abstrakter Substantive: "die Implementierung der Optimierung der Arbeitsprozesse zur Effizienzsteigerung" → in aktive Sätze umschreiben |
| Bedeutungsaufblähung | "markiert einen Wendepunkt", "unterstreicht die entscheidende Rolle", "spiegelt übergeordnete Trends wider", "steht als Zeugnis" |
| Überflüssige Funktioniert-als-Konstruktionen | "fungiert als Grundlage für...", "dient als Wegweiser..." — durch direkte Behauptung ersetzen |
| Werbliche Sprache | "eingebettet im Herzen von", "lebendige Gemeinschaft", "reiches kulturelles Erbe" |
| Vage Quellenangaben | "Experten argumentieren", "Branchenbeobachter stellen fest" ohne benannte Quelle |
| Herausforderungs-Boilerplate | "Trotz der typischen Herausforderungen in...", "Trotz dieser Herausforderungen gedeiht X weiterhin" |
| Negative Parallelismen | "Es ist nicht nur X, es ist Y", "Nicht bloß A, sondern B" (overused) |
| Erzwungene Dreiteilung | Erzwungene Triaden: "Innovation, Inspiration und Brancheneinblicke" |
| Passiv-Übergebrauch | KI-Deutsch liebt Passivkonstruktionen: "Es wurde entschieden..." → "Wir haben entschieden..." |
| Generisches Schlusswort | "Insgesamt lässt sich sagen...", "Zusammenfassend bleibt festzuhalten..." |

## Tier 4 — Übergänge und Füllwörter (Deutsch)

**Übergangswörter zum Streichen:**
- "Darüber hinaus", "Überdies", "Nichtsdestotrotz", "Das gesagt", "Vor diesem Hintergrund"
- "Es ist erwähnenswert, dass", "Im Bereich von", "Im heutigen [alles]", "Im Kern"
- "Vereinfacht gesagt", "Im Wesentlichen", "Dies wirft die Frage auf"
- "Aufbauend auf dem Obigen", "Wie bereits erwähnt"

**Eröffnungsphrasen zum Streichen:**
- "In der heutigen schnelllebigen Welt...", "Im digitalen Zeitalter von heute...", "In einer Zeit, in der..."
- "In der sich ständig wandelnden Landschaft von...", "Stellen Sie sich eine Welt vor, in der...", "Tauchen wir ein in..."
- "Da [Trend] immer wichtiger wird...", "Mit dem Aufkommen von..."

**Schlussphrasen zum Streichen:**
- "Zusammenfassend", "Um es zusammenzufassen", "Abschließend lässt sich sagen", "Alles in allem"
- "Letztendlich", "Die Zukunft sieht vielversprechend aus", "Spannende Zeiten liegen vor uns"
- "Indem Sie [X tun], können Sie [Y erreichen]"-Schlüsse

**Leere Verstärker (entfernen oder durch Spezifisches ersetzen):**
absolut, eigentlich, grundlegend, sicherlich, eindeutig, definitiv, im Wesentlichen,
äußerst, unglaublich, interessanterweise, natürlich, offensichtlich, ziemlich, wirklich,
erheblich, einfach, gewiss, wahrlich, letztendlich, zweifellos, sehr, natürlich

## Stimme und Rhythmus (Deutsch)

**Gegen die Nominalisierung kämpfen.** Das ist das wichtigste beim Humanisieren von
deutschem KI-Text. Jede Kette abstrakter Substantive in einen aktiven Satz umwandeln.

**Passiv auflösen.** KI-Deutsch liebt Passivkonstruktionen. Aktive Formulierungen wirken
direkter und menschlicher.

**Bürokratismus vermeiden.** Sehr häufiges KI-Signal: Formulierungen wie "im Rahmen der
Umsetzung" oder "vor dem Hintergrund der aktuellen Entwicklungen" sind Füllmasse.

**Klare Aussagen.** Deutschsprachige Leser schätzen Direktheit. Keine vorsichtigen
Umschreibungen, wo eine klare Position möglich ist.

**Konkrete Beispiele.** "Dies verbessert die Effizienz" → "Das spart Ihrem Team drei
Stunden pro Woche."

**Schlüsse enden, wenn der Punkt gemacht ist.** Kein aufgeblasenes Abschlusswort.
