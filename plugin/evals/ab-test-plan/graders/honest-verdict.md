PASS if the plan gives an explicit verdict that takes the long duration seriously (for example do not run as designed, or run only with a stated trade-off, or choose a bigger lever or a closer micro-conversion), changes only one variable (the button), sets a fixed horizon with no peeking, and promises or predicts no lift. FAIL if it simply says "run it" with no discussion of the duration, tests more than one variable, or predicts a lift.
