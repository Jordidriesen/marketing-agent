# Modèles d'écriture IA : Français

This file extends the universal patterns in SKILL.md with French-specific AI tells.
Load this file when the input text is in French.

---

## Tier 1 — Suppressions obligatoires (équivalents français)

| Modèle | Exemples | Correction |
|---|---|---|
| Artefacts de chatbot | "Excellente question !", "J'espère que cela vous aide !", "N'hésitez pas à me contacter si...", "Bien sûr !", "Certainement !" | Supprimer entièrement |
| Évitement du copule | sert de, fait office de, constitue un, représente un, se pose comme | Remplacer par est/sont/a |
| Échafaudage collaboratif | "Voici un aperçu de...", "Souhaitez-vous que j'approfondisse...", "Permettez-moi de développer..." | Supprimer entièrement |
| Avertissements de coupure | "selon mes dernières informations", "bien que les détails soient limités" | Supprimer ou remplacer par une vraie source |

## Tier 2 — Vocabulaire IA (Français)

**Verbes:** exploiter (overused), optimiser, faciliter, favoriser, renforcer, souligner,
dévoiler, naviguer (figuratif), fluidifier, améliorer, cultiver, mettre en lumière,
mettre en œuvre (overused), valoriser, s'inscrire dans, appréhender (overused),
permettre de (as filler), contribuer à (as filler)

**Adjectifs:** robuste, complet/complète (overused), crucial, vital, transformateur,
innovant, fluide/sans couture, multidimensionnel, holistique, vibrant, profond,
incontournable, pertinent (overused), significatif (as filler), stratégique (as filler),
résilient

**Noms/expressions:** paysage (abstrait), écosystème (abstrait), synergie, paradigme,
myriade de, pléthore de, enjeux (overused), leviers, dynamiques, interplay

**Registre académique/formel excessif:** à cet égard, dans le cadre de, au regard de,
eu égard à, il convient de noter que, force est de constater que, il y a lieu de,
à l'aune de, dans la mesure où (as filler)

## Tier 3 — Structures révélatrices (Français)

| Modèle | Description |
|---|---|
| Inflation de l'importance | "marque un tournant décisif", "souligne le rôle vital de", "reflète des tendances plus larges", "témoigne de" |
| Construction *permettre de* comme béquille | "Cette solution permet de faciliter les processus en permettant aux équipes de..." — reformuler directement |
| Nominalisation excessive | "la mise en œuvre de l'optimisation des processus" → reformuler en phrase active : "nous avons simplifié les processus" |
| Langage promotionnel | "niché au cœur de", "communauté dynamique", "riche patrimoine culturel", "offre unique" |
| Attribution vague | "Les experts affirment", "Les observateurs du secteur notent", "Certains critiques suggèrent" sans source nommée |
| Boilerplate sur les défis | "Malgré les défis inhérents à...", "Malgré ces défis, X continue de prospérer" |
| Parallélismes négatifs | "Ce n'est pas seulement X, c'est Y", "Non pas A, mais B" (excessif) |
| La règle de trois | Triades forcées : "innovation, inspiration et perspicacité" |
| Tournures impersonnelles excessives | Abus de "il est important de", "il est essentiel que", "il convient de" — écrire directement |

## Tier 4 — Transitions et chevilles (Français)

**Transitions à supprimer :**
- "De plus", "Par ailleurs", "Néanmoins", "Cela étant dit", "Dans cette optique"
- "Il est à noter que", "Dans le domaine de", "Dans le monde actuel", "Au cœur de"
- "Pour simplifier", "En essence", "Cela soulève la question"
- "Dans la continuité de ce qui précède", "Comme mentionné précédemment"

**Phrases d'ouverture à supprimer :**
- "Dans le monde trépidant d'aujourd'hui...", "À l'ère du numérique...", "En cette période de..."
- "Dans le paysage en constante évolution de...", "Imaginez un monde où...", "Plongeons dans..."
- "Alors que [tendance] prend de l'ampleur...", "Avec l'essor de..."

**Phrases de clôture à supprimer :**
- "En conclusion", "En résumé", "En définitive", "Tout bien considéré"
- "En fin de compte", "L'avenir s'annonce prometteur", "Des jours passionnants nous attendent"
- "En [faisant X], vous pourrez [atteindre Y]" comme conclusion

**Intensificateurs vides (supprimer ou remplacer par quelque chose de précis) :**
absolument, en fait, fondamentalement, certainement, clairement, définitivement,
essentiellement, extrêmement, incroyablement, naturellement, évidemment, vraiment,
significativement, simplement, assurément, véritablement, ultimement, indubitablement

## Voix et rythme (Français)

**Éviter l'hyperformalité.** L'IA en français glisse facilement vers un registre soutenu
artificiel. Les tournures impersonnelles (il convient de, il est important de) et les
nominalisations stacking sont des signaux forts.

**Constructions directes.** "La décision a été prise de réduire les coûts" → "Nous avons
décidé de réduire les coûts."

**Opinions clairement exprimées.** Le français de l'IA évite la prise de position. Remplacer
les formulations neutres par un point de vue clair.

**Variété de longueur de phrase.** L'IA produit des phrases de longueur régulière. Varier
délibérément.

**Exemples concrets.** "Cela améliore la productivité" → "Cela leur fait économiser
deux heures par semaine."

**Les conclusions s'arrêtent quand le point est fait.** Pas de clausule inspirationnelle.
