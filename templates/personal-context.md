# Personal context (template, not installed by the plugin)

The shared library under `plugin/skills/content-references/` stays client-agnostic. Keep anything specific to one owner's work here, in a private copy of this file or in a `[brand]-brand-kit` skill, and not in the shared references.

Use this file to record two things. First, the owner's recurring work mapped to the frameworks in `communication-frameworks.md`: for example executive-facing content to Minto, product launches to Sparkline, landing and solution pages to StoryBrand, ad copy and lead-gen sequences to PAS, internal updates to BLUF, and any format that fits none of them (such as a voice-led review series, where a verdict-led structure close to BLUF works better than forcing a framework). Second, caveat candidates from `behavioral-psychology.md` that the owner wants to test in their own campaigns, with the result once known. Generation skills should read the private copy only when the owner has supplied it.
