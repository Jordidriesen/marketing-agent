# Reply guide

A short guide the sender keeps next to the sequence. Replies are the whole point, so they get the same
care as the emails. Write the actual responses in the sender's voice and the recipient's language.

| Reply type | What it looks like | Response approach |
|---|---|---|
| Positive | "Yes, let's talk" | Reply fast, propose two concrete time slots, confirm the goal in one line |
| Curious | "How does it work?" | Answer in three lines, link one useful resource, ask one question that moves to a call |
| Not now | "Come back next quarter" | Thank them, agree a specific follow-up month, set a reminder, and stop the sequence |
| Objection | "We already use X" or "No budget" | Acknowledge, ask one fair question, do not argue. Use `battlecard` reframes if it is a competitor |
| Referral | "Talk to my colleague" | Thank them, ask permission to mention their name, write to the colleague as a new tier 1 contact |
| Wrong person | "Not my area" | Thank them and ask who is the right contact. Remove them from the sequence |
| Unsubscribe or "stop" | Any opt-out wording in any language | Confirm in one line if appropriate, suppress the address at once, log it. Never pitch again |
| Out of office | Automatic reply | Pause and resume after the return date. Do not count it as a reply |

Rules for all replies:

- Answer what was asked. Do not paste the pitch again.
- Never pressure. A clear "no" is a result worth having.
- Record the outcome with the reason so the sequence can improve.
